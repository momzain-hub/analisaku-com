======================================================================
1) TAMBAHKAN HELPER SETELAH f_gc() / f_bool()
======================================================================

f_stage(int code) =>
    code == 1 ? "EARLY WATCH" :
     code == 2 ? "CONFIRMED" :
     code == 3 ? "ACTIVE" : "NONE"

f_entryStyle(int code) =>
    code == 1 ? "BREAKOUT" :
     code == 2 ? "PULLBACK" :
     code == 3 ? "WEAKNESS" : "NONE"

======================================================================
2) DI DALAM f_engine(), SETELAH baris:
   bool nearTrigger = valid and not na(distTrigger) and distTrigger <= watchPct
   DAN SETELAH trendCode / statusCode SUDAH TERBENTUK,
   TAMBAHKAN BLOK BERIKUT
======================================================================

    // SETUP STAGE + ENTRY STYLE — PRIVATE CLASSIFICATION
    // Website hanya menerima label akhirnya.
    int bullBreakAgeRaw = ta.barssince(rawBullBreak)
    int bullBreakAge = na(bullBreakAgeRaw) ? 9999 : bullBreakAgeRaw

    bool confirmedNow = validBull and not invalid and (bullBreak or rawBullBreak)
    bool postBreakout = validBull and not invalid and bullBreakAge <= 20

    bool inDecisionZone = validBull and not invalid and
         not na(entryLow) and not na(entryHigh) and
         close >= entryLow and close <= entryHigh

    // Pullback: breakout sudah pernah terjadi, struktur belum invalid,
    // lalu harga kembali mendekati area referensi tanpa merusak skenario.
    float pullbackRef = math.max(priceB, e12)
    bool pullbackSetup = postBreakout and close > priceC and
         close < close[1] and
         close <= pullbackRef + atr14 * 0.75

    // Weakness: struktur bullish masih valid sebelum breakout,
    // harga masuk area keputusan dan trend utama masih mendukung.
    bool weaknessSetup = validBull and not invalid and not postBreakout and
         trendCode == 1 and inDecisionZone

    // Breakout: kandidat mendekati trigger atau baru mengonfirmasi breakout.
    bool breakoutSetup = validBull and not invalid and
         (confirmedNow or (not postBreakout and nearTrigger))

    int stageCode =
         not validBull or invalid ? 0 :
         confirmedNow ? 2 :
         postBreakout or bullishActive ? 3 :
         1

    int entryStyleCode =
         pullbackSetup ? 2 :
         weaknessSetup ? 3 :
         breakoutSetup ? 1 :
         0

Letakkan sesuai posisi parameter function yang Anda pilih; harus konsisten antara deklarasi function dan pemanggilannya.

CATATAN DESAIN
- Setup Stage dan Entry Style adalah klasifikasi engine, bukan rekomendasi transaksi.

- Formula klasifikasi tetap berada di Pine dan tidak ditampilkan frontend.
