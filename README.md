# Analisaku.com

Official website repository for Analisaku.com — edukasi saham, technical analysis, market insight, dan informasi investasi.

## Struktur awal

- `index.html` — homepage
- `technical.html` — learning path technical analysis
- `tools.html` — kalkulator investasi
- `edukasi.html` — learning center
- `artikel.html` — hub artikel dan market insight
- `about.html` — about dan disclaimer
- `assets/css/style.css` — styling utama
- `assets/js/main.js` — navigasi dan kalkulator

## Status

Website versi GitHub Pages sedang dikembangkan sebagai pengganti situs Blogger lama. Custom domain `analisaku.com` akan dipindahkan setelah versi baru selesai diuji.
